# NS Perfumes & N.S Detergents

Website for NS Perfumes (perfumes, R150 per 100ml) and N.S Detergents (cleaning products in several sizes). A women-owned business.

## How to use this repo
1. Add the four perfume stickers to `assets-in/` as `red-door.png`, `tsar.png`, `poison.png`, `dolce-gabbana.png`.
2. Open an empty folder with this repo in Claude Code and paste the prompt from `PROMPT.md`.
3. Claude Code builds the Next.js site, which will replace the placeholder content here.

## Contents
- `PROMPT.md` : the full Claude Code build prompt
- `assets-in/` : logo and sticker images
